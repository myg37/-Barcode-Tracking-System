# -Barcode-Tracking-System
A professional Windows Forms desktop application for  institutional barcode tracking and management, developed  during my internship period.
## 📌 About This Project
This application was developed as a real-world business tool
for tracking barcodes between institutions. It is actively
used in a production environment.

## ✨ Features
- Barcode range entry and batch processing
- Transaction-based secure data saving
- Duplicate barcode detection and skipping
- Excel import with ClosedXML
- Barcode listing, editing and deletion
- Right-click context menu for quick actions
- AutoComplete for institution names
- Date validation (production & expiry dates)
- Domestic/International barcode type selection
- User login system with shake animation
- CapsLock warning on password field
- Async/await for non-blocking UI

## 🛠️ Tech Stack
- C# Windows Forms (.NET Framework)
- SQL Server (SQLEXPRESS)
- ClosedXML (Excel processing)
- ADO.NET

## ⚙️ Configuration
Update the connection string in `DbConfig.cs`:
```
Data Source=YOUR_SERVER;Initial Catalog=YOUR_DB;Integrated Security=True;
```
